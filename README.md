# BudgieGTA — Open-World PC Game

An original open-world action-adventure game project. This repository is a playable-prototype foundation, not Rockstar's GTA 6 and not affiliated with Rockstar Games.

## Coding assistant
Use Claude Code (5.2 if available in your installation) with the instructions in [CLAUDE.md](CLAUDE.md). Model availability and naming are controlled by the Claude Code account and installation; this repository cannot switch the model automatically.

## Engine
- Godot 4.x
- GDScript
- Initial target: Windows PC (x86_64)
- Renderer: Godot Forward+
- Original setting, characters, missions, vehicles and assets only

## Current starter
- First-person-free third-person character controller
- Camera-relative movement and mouse-look
- Jumping and gravity
- Small blockout test scene
- Project roadmap and Claude Code build instructions

## Run
1. Install Godot 4.x.
2. Open the `game/project.godot` file in Godot.
3. Press F6 to run the main scene or F5 to run the project.

## Roadmap
See [docs/ROADMAP.md](docs/ROADMAP.md). A full commercial-scale open-world game requires a large team, original art/audio, extensive testing and a long production schedule. This repository builds it in small, testable milestones.
