## Rules
- Build an original game; do not copy GTA 6 source code, proprietary assets, maps, characters, dialogue, missions, logos or branding.

- Prefer small, complete changes. Before editing, inspect the existing project and summarize the plan.
- Add tests or reproducible manual test steps for every feature.

For each milestone: inspect files, implement, run available validation, list limitations and exact run steps. Do not pretend unfinished systems are complete.
